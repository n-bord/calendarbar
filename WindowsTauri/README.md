# CalendarBar 1.0.0 для Windows

Установщик x64 использует системный WebView2 и скачивает его, если он отсутствует. В списке приложений и меню «Пуск» приложение называется **CalendarBar**. Установщик без цифровой подписи. Версию 1.0.0 можно установить поверх 0.7.1–0.7.4.

Для корпоративных ПК есть отдельный установщик **PerUser**. На первом экране он указывает, что CalendarBar установится для текущего пользователя без запроса прав администратора. Он использует установленный Microsoft Edge WebView2 Runtime. Если компонента нет, мастер предложит обратиться в ИТ-службу. Корпоративные правила запуска программ действуют и для установки в профиль пользователя.

При переходе с **CalendarBar Tauri 0.7.0** закройте его через «Выход» в трее и удалите старую версию, оставив опцию удаления данных приложения выключенной. Затем установите 1.0.0. Она откроет существующий профиль с вашими аккаунтами и настройками.

При первом запуске Tauri копирует профиль Electron у того же пользователя Windows. У исходной версии остаются её файлы. Переносятся аккаунты, кэш, история, настройки, закрепления, цвета и напоминания. Сохранённые пароли Windows переносит в защищённое хранилище Tauri. Если пароль не удаётся восстановить, откройте **Настройки → Подключение** и повторно введите пароль приложения Яндекс ID типа «Календарь». Автозапуск Tauri включается отдельно в разделе «Основные».

В трее и настройках доступны поиск, закрепления, история, график синхронизации и очистка кэша. Поиск загружает выбранный период до трёх лет. Создание, редактирование и ответы на приглашения открывают Яндекс Календарь в браузере. После закрытия окон CalendarBar продолжает синхронизацию и напоминания. Для завершения работы выберите **Выход** в трее.

## Проверка на Windows

1. Нажмите на значок CalendarBar в трее. Проверьте, что панель открывается сразу с содержимым, закрывается по Escape и при переключении на другое приложение, затем снова открывается по значку.
2. Проверьте аккаунты, календари, цвета, личные напоминания и закрепления из старого профиля.
3. С открытыми календарём и карточкой встречи измените цвет встречи. Карточка должна остаться открытой, а остальные встречи должны оставаться в календаре после смены цвета и обновления. Проверьте также повторяющиеся встречи и поиск за прошлый период без сети после синхронизации.
4. В **Настройки → Уведомления** отправьте тестовое уведомление. Если Windows приняла его, но баннер не появился, откройте центр уведомлений (Win + N в Windows 11). Если проверка завершилась ошибкой, в настройках видно, на каком шаге произошёл сбой. Для реальной встречи проверьте кнопки «Подключиться», «Через 5 минут», «В начале встречи» и «Больше не напоминать».
5. Очистите кэш одного аккаунта и проверьте общий объём в **Настройки → Кэш календаря**. Личные настройки и данные второго аккаунта должны сохраниться.
6. Чтобы сравнить память, измерьте каждую версию по очереди с одинаковым аккаунтом, периодом и размером окон. Проверьте режим ожидания в трее, открытую неделю и поиск за два года. Скрипт Windows учитывает дерево процессов, включая процессы WebView2, если они запущены как потомки CalendarBar.

```powershell
.\scripts\Measure-CalendarBar.ps1 -RootProcessId 12345
```

## Сборка

На Windows нужны Rust Stable, Node.js и Visual Studio Build Tools с C++ и Windows SDK. Из папки `CalendarBar\WindowsTauri` выполните:

```powershell
npm ci
node scripts/prepare-app.cjs
cargo test --manifest-path src-tauri/Cargo.toml
npm run build:windows
```

Установщик появится в `src-tauri\target\x86_64-pc-windows-msvc\release\bundle\nsis\`. На Mac для сборки под Windows дополнительно нужны LLVM, cargo-xwin и NSIS. После `npm ci` запустите `npm run build:windows -- --runner cargo-xwin`.

Вариант для корпоративных ПК собирается командой `npm run build:windows:per-user`. На Mac добавьте `-- --runner cargo-xwin`. Обе команды выводят файл с одним именем, поэтому при сборке обоих вариантов сохраните первый файл в другой папке перед второй сборкой.

## Демо интерфейса

Из корня репозитория:

```sh
npm ci --prefix WindowsTauri/demo
npm --prefix WindowsTauri run start:electron
```

Для галереи README запустите `npm --prefix WindowsTauri run start:electron -- --screenshots`. Скриншоты сохранятся в `docs/screenshots`. Демо использует вымышленные данные, а производственная сборка берёт интерфейс из `renderer/`.
