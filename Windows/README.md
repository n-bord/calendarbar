# CalendarBar для Windows 0.6.4

На Windows 10 и 11 (x64) запустите `CalendarBar-Windows-0.6.4-x64-Setup.exe`. При обновлении сначала завершите CalendarBar через «Выход» в мини-меню. При первом запуске введите e-mail и пароль приложения Яндекс ID типа «Календарь». Значок CalendarBar открывает мини-меню в области уведомлений. Закрытие окна оставляет CalendarBar запущенным.

В окне календаря работают Ctrl+F (поиск), Ctrl+N (создание на сайте), Ctrl+T (сегодня) и Ctrl+, (настройки). Календарь использует локальный часовой пояс Windows. В настройках подключения часовой пояс аккаунта помогает прочитать события без собственного часового пояса.

Windows показывает напоминания, пока CalendarBar запущен, в том числе в фоне при закрытом окне. При выходе или длительном сне напоминание может быть пропущено. Автозапуск включается в «Настройки → Основные». Учетные записи добавляются в Windows отдельно, пароли приложений хранятся с защитой Windows DPAPI.

В «Настройки → Кэш календаря» показывается общий объём сохранённых событий и объём по аккаунтам. Очистить можно один аккаунт или все. Пароли, настройки, история, закрепления и личные напоминания сохраняются. При следующем обновлении ближайшие встречи загрузятся заново.

## Сборка из исходников

Из папки Windows выполните команды с Node.js 22.12 или новее. Для установки зависимостей и первой сборки нужен интернет.

```powershell
npm ci
npm test
npm run dist:win
```

Установщик появится в `../dist/windows/`. Для запуска из исходников используйте `npm start`.
