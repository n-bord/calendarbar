# Разработка CalendarBar для macOS

Приложение использует SwiftUI и AppKit. Для сборки нужен полный Xcode 16 или новее. Приложение работает на macOS 13 и новее. Локальный расчёт повторений доступен начиная с macOS 15.

Из корня репозитория:

```sh
./Build.command --build-only
```

Скрипт запускает тесты SwiftPM и создаёт `dist/CalendarBar.app` для архитектуры текущего Mac. Только тесты можно запустить командой `swift test` с выбранным полным Xcode.

Для демонстрации без рабочего аккаунта:

```sh
./script/build_and_run.sh --demo
```

Меню **Демо** открывает панель встреч, календарь и настройки. Приложение использует вымышленные встречи и отдельный профиль. Синхронизация и системные напоминания в демо отключены.
